# 📓 Learning Journal

Mon journal d'apprentissage pour devenir **Admin Sys & Réseau → Ingénieur Infra → DevOps → DevSecOps**.

Chaque notion est testée en lab, puis documentée ici : ce qui a marché et ce qui a planté.

## 🧭 Parcours

Linux → Réseau → Windows Server → Virtualisation → Docker → Kubernetes → Terraform / Ansible → CI/CD → Observabilité → Sécurité

## 📂 Structure

| Dossier | Contenu |
|---|---|
| `linux/` | Administration Linux, Bash, services |
| `reseau/` | TCP/IP, VLAN, routage, firewall |
| `docker/` | Conteneurs, images, Compose |

D'autres dossiers seront ajoutés au fil de l'avancement (kubernetes, terraform, ci-cd, securite...).

## 🧪 Méthode

Un lab = un fichier, toujours structuré ainsi :

1. **Objectif** : ce que je veux faire
2. **Commandes** : ce que j'ai tapé
3. **Résultat** : ce que j'ai obtenu
4. **Ce qui a planté** : problème, cause, solution
